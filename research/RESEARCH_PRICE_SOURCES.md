# Research: Palm Oil & Rubber Prices

**เวลาตรวจสอบ:** 22 กันยายน 2569 (พ.ศ. 2026) ตามเวลาประเทศไทย

## 1. Executive Summary

การสำรวจพบว่าไม่มีแหล่งเดียวที่ให้ทั้ง **ความเป็นข้อมูลท้องถิ่นระดับพัทลุง**, **ข้อมูลเครื่องอ่านได้**, และ **เงื่อนไขการใช้ที่ชัดเจน** พร้อมกัน แหล่งที่เหมาะสมจึงต้องแยกตามวัตถุประสงค์

**แหล่งที่ตรงพัทลุงที่สุด** คือสำนักงานเกษตรและสหกรณ์จังหวัดพัทลุง ซึ่งเผยแพร่ราคาปาล์มน้ำมันและยางพารารายวันผ่านหน้าเว็บราชการและไฟล์ภาพ PNG [1] [2] ข้อมูลมีจังหวัด ผู้รับซื้อ/โรงงาน ประเภทสินค้า วันที่ และหน่วยบาทต่อกิโลกรัม แต่ยังไม่มี API หรือ JSON ที่ยืนยันได้ และนโยบายเว็บไซต์จำกัดการใช้สคริปต์นอกช่องทางที่จัดไว้ ดังนั้นยังไม่ควรนำไปดึงอัตโนมัติโดยไม่ได้รับอนุญาต

**แหล่งที่เหมาะกับการดึงอัตโนมัติที่สุด** คือ OAE Catalog และ Agri API ซึ่งเป็น JSON มี pagination และประวัติย้อนหลัง แต่ข้อมูลราคาปาล์มและยางที่ตรวจสอบเป็น **ราคาที่เกษตรกรขายได้ ณ ที่ไร่นา เฉลี่ยระดับประเทศ** ไม่ใช่ราคาพัทลุงหรือราคาหน้าโรงงานภาคใต้ [3] [4]

สำหรับปาล์มน้ำมัน **กรมการค้าภายใน (DIT)** เป็นแหล่งอ้างอิงภาคใต้ที่มีประโยชน์ เพราะมีรายงาน PDF รายวันของผลปาล์มทะลายและระบุแหล่งผลิตสำคัญ เช่น สุราษฎร์ธานี กระบี่ และชุมพร รวมทั้งมีรายงานจากสำนักงานพาณิชย์จังหวัดพัทลุง [5] อย่างไรก็ดี รูปแบบหลักเป็น PDF และ Website Policy ไม่เปิดให้ใช้สคริปต์อัตโนมัตินอกช่องทางที่จัดไว้โดยไม่ได้รับอนุญาต

สำหรับยางพารา **RAOT/MISDATA** และ **สมาคมยางพาราไทย (TRA)** มีความเกี่ยวข้องกับภาคใต้โดยตรง โดยมีตลาดสงขลา หาดใหญ่ นครศรีธรรมราช สุราษฎร์ธานี ตรัง ภูเก็ต และยะลาในตารางที่ตรวจสอบ [6] [7] แต่ต้องแยกชนิดยางและประเภทราคาอย่างเข้มงวด เพราะตารางหนึ่งอาจเป็นราคาปิดตลาด อีกตารางเป็นราคาท้องถิ่นหรือราคาเสนอขาย FOB และบางหน้าของ RAOT ไม่ระบุหน่วยราคาชัดเจน

### ข้อเสนอเพื่อการพิจารณาของมนุษย์

1. หากต้องการ **ราคาพัทลุงจริง** ให้พิจารณา OPSMOAC พัทลุงเป็นแหล่งหลักเชิงเนื้อหา แต่ต้องขออนุญาตหรือประสานหน่วยงานก่อนทำระบบอ่านภาพอัตโนมัติ
2. หากต้องการ **ระบบที่ดึงได้เสถียร** ให้พิจารณา OAE JSON เป็นแหล่งระดับประเทศ โดยต้องประกาศให้ชัดว่าเป็นราคาที่เกษตรกรขายได้เฉลี่ยระดับประเทศ ไม่ใช่ราคาพัทลุง
3. หากต้องการ **บริบทภาคใต้สำหรับตรวจสอบไขว้** ให้พิจารณา DIT สำหรับปาล์ม และ RAOT/TRA สำหรับยาง โดยเก็บชนิดสินค้า วันที่ หน่วย พื้นที่ และประเภทราคาไว้ทุกครั้ง
4. ยังไม่ควรเลือกตัวเลขหนึ่งตัวไปพูดในรายงานเช้า และยังไม่ควรเพิ่มข้อมูลลง production จนกว่ามนุษย์จะกำหนดสินค้า ประเภทราคา พื้นที่ และกติกา fallback อย่างชัดเจน

### ตัวอย่างข้อมูลจริงที่ยืนยันได้

- **พัทลุง:** ภาพประกาศวันที่ 22 กันยายน 2569 แสดงบริษัท ยูนิวานิช น้ำมันปาล์ม จำกัด (มหาชน) รับซื้อปาล์มทะลายที่ **8.60–8.70 บาท/กก.** และลานเทที่ **8.40–8.50 บาท/กก.** โดยเป็นช่วงราคาตามผู้รับซื้อ ไม่ใช่ค่าเฉลี่ยที่ผู้วิจัยคำนวณ [2]
- **DIT ภาคใต้:** PDF วันที่ 21 กันยายน 2569 แสดงปาล์มทะลายโรงงานรับซื้อ คุณภาพน้ำมัน 18% ในแหล่งผลิตสำคัญ 3 จังหวัดที่ **8.10–8.80 บาท/กก.** ค่าเฉลี่ย **8.53 บาท/กก.** [5]
- **OAE ระดับประเทศ:** API รายเดือนที่ตรวจสอบแสดงผลปาล์มน้ำมันทั้งทะลาย คละ เดือน 08/2569 ที่ **8.38 บาท/กก.** และ API รายสัปดาห์สัปดาห์ที่ 5 ของเดือนเดียวกันที่ **8.17 บาท/กก.** แถวข้อมูลระบุพื้นที่ประเทศไทย ไม่ใช่พัทลุง [3] [4]

## 4. Detailed Source Profiles

### 4.1 OPSMOAC Phatthalung — Primary local candidate

หน่วยงานคือสำนักงานเกษตรและสหกรณ์จังหวัดพัทลุง สำนักงานปลัดกระทรวงเกษตรและสหกรณ์ เว็บไซต์มีรายการ “ราคาปาล์มน้ำมันประจำวันที่ 22 กันยายน 2569” และ “ราคายางพาราประจำวันที่ 22 กันยายน 2569” อยู่ในหมวดสถานการณ์การผลิตและการตลาด [1] ข้อมูลตัวเลขอยู่ในภาพ PNG ที่แนบกับบทความ จึงเป็นหลักฐานต้นฉบับที่ต้องเก็บ URL และวันที่ไว้ ไม่ควร OCR แล้วทิ้งภาพต้นฉบับ

ข้อดีคือพื้นที่ตรงกับผู้ใช้งานและแยกผู้รับซื้อ/ชนิดยางได้ ข้อจำกัดคือไม่มี machine-readable feed ที่ยืนยันได้ ไม่มี methodology ของการคำนวณ และนโยบายเว็บไซต์ MOAC ห้ามการเข้าถึงด้วยสคริปต์นอกช่องทางที่จัดไว้หากไม่ได้รับอนุญาต [11] จัดเป็น **Primary Candidate เชิงพื้นที่ แต่ Automation ยัง Uncertain**

### 4.2 DIT — Primary regional palm candidate

กรมการค้าภายในเผยแพร่รายงานราคาผลปาล์มและน้ำมันปาล์มรายวันเป็น PDF รายเดือน รายงานระบุผลปาล์มทะลายที่โรงงานรับซื้อและคุณภาพน้ำมัน 18% พร้อมช่วงต่ำ–สูงและค่าเฉลี่ย [5] หน่วยงานพาณิชย์จังหวัดพัทลุงมีบทความภาคสนามที่รายงานราคาหน้าโรงงานสกัดในจังหวัด แต่วันที่ล่าสุดที่พบตัวเลขพัทลุงในงานนี้คือ 27 สิงหาคม 2568 ขณะที่ประกาศวันที่ 22–24 สิงหาคม 2569 บางชิ้นเป็นข่าวตรวจการแสดงราคาโดยไม่มีตัวเลข

จัดเป็น **Primary Candidate สำหรับราคาอ้างอิงปาล์มภาคใต้** เมื่อผู้ใช้ยอมรับความแตกต่างระหว่างราคาแหล่งผลิตสำคัญกับราคาเฉพาะพัทลุง ส่วนการดึงอัตโนมัติต้องขออนุญาตตาม Website Policy ของกระทรวงพาณิชย์ [12]

### 4.3 OAE — Primary machine-readable candidate

OAE Catalog ระบุชัดว่าราคาปาล์มเป็นราคาที่เกษตรกรขายได้ ณ ไร่นา รายสัปดาห์ ระดับประเทศ และ resource เป็น JSON [3] API มีฟิลด์สินค้า พื้นที่ ปี เดือน/สัปดาห์ ค่า และหน่วย รวมทั้ง pagination มีประวัติย้อนหลัง [4] สำหรับยางมีชุดรายเดือนและรายสัปดาห์ที่แยกยางแผ่นดิบชั้น 3 ยางก้อน และน้ำยางสด [10]

จัดเป็น **Primary Candidate ด้านการอัตโนมัติ** หากรายงานยอมรับราคาประเทศและระบุความหมายนี้ตรง ๆ ไม่ควรเรียกเป็น “ราคาพัทลุง” หรือ “ราคาหน้าโรงงาน”

### 4.4 RAOT / MISDATA — Secondary rubber candidate

RAOT เป็นหน่วยงานรัฐและหน้าราคายางพาราเชื่อมไปยัง MISDATA สำหรับราคาซื้อขายผ่านตลาดกลาง [6] ตารางมีชนิดยางและวันที่ รวมทั้งตลาดภาคใต้ เช่น สงขลา นครศรีธรรมราช สุราษฎร์ธานี และยะลา แต่ตารางที่ตรวจสอบไม่ระบุหน่วยราคาอย่างชัดเจน จึงต้องแก้ปัญหานี้ก่อนนำไปพูดหรือเปรียบเทียบ

จัดเป็น **Secondary / Backup Candidate** สำหรับตรวจสอบยางภาคใต้ ไม่ใช่ source ที่ควรนำไปใช้ทันทีโดยไม่ตรวจ data dictionary และหน่วย

### 4.5 TRA — Secondary rubber candidate

เว็บไซต์สมาคมยางพาราไทยมีราคาท้องถิ่นรายวันพร้อมหน่วยบาทต่อกิโลกรัม และระบุชัดว่าเป็นข้อมูลเบื้องต้นเพื่อช่วยตัดสินใจซื้อขายเท่านั้น [7] หน้าเดียวกันมีจุดอ้างอิงภาคใต้หลายแห่ง ส่วนตลาดกลางสงขลามีตารางแยก USS, RSS3, น้ำยางสด และเศษยาง [9]

จัดเป็น **Secondary / Backup Candidate** เพราะข้อมูลสดและตรงภาคใต้ แต่ไม่มี API ที่ประกาศและข้อกำหนดการใช้ข้อมูลซ้ำไม่ชัดเจน

### 4.6 Songkhla Central Rubber Market — Regional reference

ตลาดกลางยางพาราจังหวัดสงขลาเป็นข้อมูลตลาดภาคใต้ที่มีประโยชน์ต่อการ cross-check แต่ไม่ใช่ข้อมูลพัทลุง และตารางต่างชุดมีวันที่ล่าสุดไม่เท่ากัน จึงต้องไม่รวมราคา MISDATA, TRA local และ TRA central เป็น series เดียวกัน [6] [7] [9]

จัดเป็น **Reference / Secondary Candidate** ขึ้นกับว่าจะยืนยันหน่วยและวิธีคำนวณได้หรือไม่

### 4.7 Palm Oil Crushing Mill Association — Reference only

สมาคมโรงงานสกัดน้ำมันปาล์มมีเอกสารหลักเกณฑ์และเงื่อนไขการรับซื้อผลปาล์มตามอัตราน้ำมัน แต่หน้าที่ตรวจสอบไม่แสดงตัวเลขราคาปัจจุบัน หน่วย พื้นที่ หรืออนุกรมราคา [8] เว็บไซต์มี WordPress REST API และ RSS แต่ยังไม่พบ endpoint ที่เป็นชุดราคาจริง

จัดเป็น **Reference Only** และไม่ควรใช้เป็น source ราคาปัจจุบันจนกว่าจะได้รับไฟล์หรือ endpoint ที่ยืนยันได้จากสมาคม

### 4.8 OAE Southern Regional Context — Context only

สำนักงานเศรษฐกิจการเกษตรเขต 9 ให้บริบทภาคใต้และมีพื้นที่รับผิดชอบที่เกี่ยวข้องกับสงขลา สตูล พัทลุง และตรัง แต่ข้อมูลที่ตรวจสอบไม่ใช่ feed ราคาพัทลุงโดยตรง จึงใช้เป็นบริบทและช่องทางประสานงาน ไม่ใช้เป็นตัวเลขราคาแทน [13]

## 11. Risks

ความเสี่ยงหลักคือเว็บไซต์ภาครัฐบางแห่งเผยแพร่ตัวเลขเป็นภาพหรือ PDF ทำให้ OCR และการเปลี่ยน layout ทำให้เกิดความผิดพลาดได้ นอกจากนี้บางแหล่งมีราคาเฉพาะวันที่ทำการซื้อขายและมีช่องว่าง ซึ่งไม่ควรแปลงเป็นศูนย์

ราคาแต่ละ source มีคนละนิยาม ทั้งระดับไร่นา หน้าโรงงาน ตลาดกลาง ราคาท้องถิ่น และราคา FOB การนำมาแสดงรวมกันโดยไม่ระบุชนิดจะทำให้ชาวบ้านเข้าใจผิดได้

ข้อมูล OAE มีความเหมาะสมด้าน API แต่เป็นค่าเฉลี่ยระดับประเทศและมีเงื่อนไข Non-Commercial ส่วนข้อมูลพัทลุงตรงพื้นที่แต่ยังไม่มี API และมี policy จำกัด automation

แหล่งข้อมูลที่มีวันที่ล่าสุดอาจเปลี่ยนหรือแก้ย้อนหลังได้ ระบบในอนาคตควรเก็บ raw response, image/PDF ต้นฉบับ, hash, วันที่ตรวจ และ URL ไม่ควรเก็บเฉพาะตัวเลขที่แยกออกมา

## 12. Suggested Next Step

มนุษย์ควรตัดสินใจแยกเป็นสองทางเลือก ไม่ควรเลือก source เดียวโดยอัตโนมัติ ทางเลือกแรกคือใช้ OPSMOAC พัทลุงเป็นข้อมูลท้องถิ่นและประสานขอช่องทางข้อมูลที่ได้รับอนุญาต ทางเลือกที่สองคือใช้ OAE เป็นแหล่ง API แต่ประกาศว่าเป็นค่าเฉลี่ยระดับประเทศ และใช้ DIT/RAOT/TRA เป็นแหล่งตรวจสอบภาคใต้

ถ้าได้รับอนุญาตให้ทำต่อ ควรสร้าง research-stage adapter ที่คืนโครงสร้างเดียวกัน เช่น `commodity`, `productType`, `priceType`, `unit`, `area`, `observedDate`, `valueMin`, `valueMax`, `value`, `source`, `evidenceUrl`, `retrievedAt` และ `rawArtifact`. Adapter ต้องปฏิเสธข้อมูลที่ไม่มีวันที่ หน่วย หรือประเภทสินค้า และต้องไม่ส่งข้อมูลเข้า production จนกว่าจะมีมนุษย์อนุมัติ

## 13. Human Decision Required

มนุษย์ต้องอนุมัติประเด็นต่อไปนี้ก่อนเริ่มแก้ production:

1. จะรายงานราคาปาล์มจากพัทลุงแบบช่วงต่ำ–สูงหน้าโรงงาน/ลานเท หรือใช้ค่าเฉลี่ยระดับประเทศจาก OAE
2. จะรายงานยางชนิดใด เช่น RSS3 ยางแผ่นดิบ น้ำยางสด หรือยางก้อนถ้วย
3. จะยอมรับข้อมูลภาคใต้จากสงขลา/หาดใหญ่เป็น proxy ของพัทลุงหรือไม่
4. จะขออนุญาตหน่วยงานก่อนดึงภาพ/PDF อัตโนมัติหรือไม่
5. จะใช้ข้อมูล OAE ภายใต้เงื่อนไข Non-Commercial และ attribution อย่างไร
6. จะให้เสียงพูดเพียงตัวเลขหลักหรือพูดทั้งประเภทสินค้า พื้นที่ วันที่ และข้อจำกัด
