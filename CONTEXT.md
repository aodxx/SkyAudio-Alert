## Current product

น้องจุ่นจ้าน sends a flood-first morning report to the บ้านลำพาย LINE group around 06:00 Asia/Bangkok.

Priority:
1. Flood situation
2. Weather forecast as supporting context
3. Safety/action guidance

Delivery:
1. Compact Flood-first Flex
2. Adaptive Thai Audio generated by Gemini TTS

## Current implementation

The repository contains FloodSituation contract/adapter, Weather normalization/analyzer, Gemini ReportDraft content layer, flood-first pipeline, compact flood-first Flex, Gemini TTS configuration/adapter, audio validation/storage, LINE adapter, dry-run and duplicate guard.

The implementation is not production-ready.

## Open blockers

- B1: flood source is currently a strict server-rendered HTML adapter, not a formally guaranteed machine-readable API
- B2: degraded mode must remain explicitly accepted as unknown + weather or another final policy
- B3: Gemini content/TTS model, endpoint, voice and response contract must be verified with the real API key
- B4: docs/tests/workflows must remain aligned with this lock

## Rules

- Gemini never becomes source of truth
- forecast never proves actual flooding
- no market/news in production
- no fixed audio duration
- no fixed spoken order
- unknown data must be stated as unknown
- production schedule stays closed until acceptance

Future PWA/community-platform ideas remain deferred and are not part of this milestone.
